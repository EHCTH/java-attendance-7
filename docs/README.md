## 기능 요구 사항

### 도메인

| 기능                  | 세부설명                                                                                    |
|---------------------|-----------------------------------------------------------------------------------------|
| MenuOption          | - 1,2,3,4,Q 등 메뉴 옵션을 받는다                                                                |
| Name                | - 사용자 이름                                                                                |
| Period              | - 등교 날짜 및 시간                                                                            |
| Records             | - `Period` 일급 컬렉션                                                                       |
| Attendance          | -`Name`,  `Records`                                                                     |
| Expire(`enum`)      | - 제적(결석 5회 초과)<br/>- 면담(결석 3회 이상)<br/>- 경고(결석 2회 이상)<br/>- 지각 3회는 결석 1회로 간주한다.          |
| Status(`enum`)      | - 결석(해당 요일 별 시작 시각으로 부터 30분 초과 및 기록이 없을 경우)<br/>- 지각(해당 요일 별 시작 시각으로 부터 5분 초과)<br/>- 출석 |
| CampusTime(`enum`)  | - 캠퍼스 시간(OPEN, CLOSE)<br/>- 08 ~ 23                                                     |
| LectureTime(`enum`) | - 요일별 시간(OPEN, CLOSE)<br/>- 월요일 13:00~18:00<br/>- 화요일~금요일은 10:00~18:00이다                |
|                     |                                                                                         |

### 기능

- (1)출석
    - 닉네임 입력 ex) `이든`
    - 등교 시간 입력 ex) `09:59`
```java 
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59
12월 13일 금요일 09:59 (출석)
```


- (2)수정
    - 닉네임 입력 ex) `빙티`
    - 수정 할 날짜 입력 ex) `3`
    - 수정 할 시간 입력 ex) `09:58`

```java
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
```
- (3)크루 별 조회
    - 닉네임 입력 ex) `빙티`
    - 시간 오름차 순으로 정렬

```java
닉네임을 입력해 주세요.
빙티

이번 달 빙티의 출석 기록입니다.

12월 02일 월요일 13:00 (출석)
12월 03일 화요일 09:58 (출석)
12월 04일 수요일 10:02 (출석)
12월 05일 목요일 10:06 (지각)
12월 06일 금요일 10:01 (출석)
12월 09일 월요일 --:-- (결석)
12월 10일 화요일 10:08 (지각)
12월 11일 수요일 --:-- (결석)
12월 12일 목요일 --:-- (결석)

출석: 4회
지각: 2회
결석: 3회

면담 대상자입니다.
```
- (4)제적 상태 확인
    - 제적 상태가 경고 이상일 경우 전부 확인, SAFE일 경우 필터링 
    - 정렬 순서는 지각을 결석으로 간주하여 내림차순한다. 출석 상태가 같으면 닉네임으로 내림차순 정렬한다.
```java
제적 위험자 조회 결과
- 빙티: 결석 3회, 지각 2회 (면담)
- 이든: 결석 2회, 지각 4회 (면담)
- 쿠키: 결석 2회, 지각 2회 (경고)
- 빙봉: 결석 1회, 지각 5회 (경고)
```
- (Q)나가기
    - 그냥 나가기

### 예외
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 IllegalArgumentException을 발생시킨 후 예외 발생한 곳에서 재 입력받는다


| 기능    | 세부설명                                                                                                        |
|-------|-------------------------------------------------------------------------------------------------------------|
| 이름 입력 | -등록되지 않을 경우 예외 발생                                                                                           |
| 출석    | -캠퍼스 운영시간이 아닐 경우 예외 발생<br/>-주말 및 공휴일일 경우 예외 발생<br/>-이미 출석을 하였는데 또 출석을 할 경우 예외 발생<br/>-수정하려는 날짜가 없을 경우 예외 발생<br/> |
| 날짜    |-날짜 형식이 잘못되었을 경우
